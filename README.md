# LogSeq Google Drive Graph Sync Plugin
- This plugin allows you to sync your LogSeq graph with Google Drive, enabling seamless access and backup of your notes across devices.

## Features
- Sync your LogSeq graph with Google Drive in real-time.
- Automatic backup of your notes to Google Drive.
- Restore your LogSeq graph from Google Drive if needed.
- Easy setup and configuration through the LogSeq plugin interface.
